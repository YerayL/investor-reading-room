## 开始阅读

**直接阅读。** [下载离线阅读包](https://github.com/YerayL/investor-reading-room/releases/latest/download/investor-reading-room-offline.zip)，将整个压缩包解压后双击 `index.html`。笔记、手册和介绍视频均可离线打开。

**从源码运行。** 下载或克隆仓库，在项目目录运行：

```sh
python serve.py
```

使用 Python 3，在浏览器打开 [本机投资文稿馆](http://127.0.0.1:8726/)。也可以将项目目录交给普通静态文件服务器。阅读笔记和手册使用本地数据，打开机构官网原文时才需要联网。

| 从哪里开始 | 能读到什么 |
| --- | --- |
| 文稿 | 按投资人、语言或类型筛选，每篇都有论证、案例、个人应用、适用条件与出处。 |
| 投资人 | 从同一位作者的不同时期和不同场合进入文稿，部分中英文版本可以直接切换。 |
| 个人投资手册 | 围绕估值、卖出、投资期限、费用、仓位等 12 个问题，比较不同作者的论证，并把结论带回自己的持仓。 |

## 三个阅读例子

下面的详读链接对应源码版的本机地址。使用离线版时，可以在文库中搜索题名。

- **李录在 2024 年北大光华的演讲。** 从居民储蓄怎样转化成有效资本，读到怎样在承受回撤时仍能持有企业。六条原则在英文稿第 23 页、中文稿第 27 页。两套笔记使用各自版本的页码。[英文稿详读](http://127.0.0.1:8726/#/read/592) · [中文稿详读](http://127.0.0.1:8726/#/read/593)
- **帕伯莱在 2016 年北大课堂复盘 Tesoro。** 买入后的价格下跌、炼油价差修复和经理继续配置资本，是三个不同的问题。课堂实录还讨论了提前卖出一家能长期增长的公司会失去什么。[课堂详读](http://127.0.0.1:8726/#/read/752)
- **马克斯的备忘录。** 1990 年的一封短信对比了两种追求优秀业绩的做法。一家养老金很少拿到单年最高名次，14 年累计却排进同类前 4%。可以在全本或精选本内展开同一篇，并沿相应版本的页码核对。[马克斯备忘录全本](http://127.0.0.1:8726/#/read/191)

## 资料与页码

- 馆藏的 446 份 PDF 与 480 份网页按文件计数。同一活动的语言版本、独立节选和官方合订本分别保留，方便对照。
- 马克斯全本收录 162 篇备忘录，精选本的 45 篇与全本重合，页码按各自版本标注。Idealab 的 25 堂创业课也可逐课阅读。
- PDF 使用文件物理页。网页使用本馆保存版本的正文段号，官网排版更新后可能变化。整期刊物以题名指定的访谈为阅读范围，年报以管理人致信、持仓讨论及相关问答为重点。
- 中文笔记区分发言者观点、整理者的个人应用和判断条件。涉及市场、利率、企业经营及政策的数字均应结合文稿日期阅读。
- 各份资料保留公开来源与原文件链接。已有本地原稿可在阅读器中关联目录；本地文件只在自己的浏览器内读取。原始 PDF、网页全文及第三方图表的权利归相应权利人。
- 李录名下收录 32 份资料。喜马拉雅资本中英文目录中 19 个带题名的 PDF 均已逐个比对文件指纹，另收录了哥大保存的 2013 年整期原刊。[喜马拉雅资本中文目录](https://www.himcap.com/cn/publications) · [英文目录](https://www.himcap.com/publications) · [哥大 Heilbrunn Center](https://business.columbia.edu/heilbrunn/about/annual-letter)

## 定位到网页中的一段

在书库底部选择「关联本地原文」，选中含各投资家子目录的文件夹。此后点击笔记中的「第 106 段」即可打开该段和上下文。阅读器用 SHA-256 核对文件版本，按馆藏正文的顺序编号。按页引用的 PDF 可直接打开所列物理页。

需要为离线资料目录重建带段号的阅读副本时，安装 `beautifulsoup4`，然后运行下面的命令，将引号中的路径换成你的原文目录。生成文件只写入该目录的 `data/paragraphs/`。

```sh
python tools/index_html.py "原文目录"
```

## 项目结构

- `index.html` 与 `assets/` 提供静态阅读器。
- `data/library.json` 存放文稿元数据、分节详读、原文位置和版本关系。
- `data/guide.json` 存放个人投资手册、案例和参考文稿。
- `media/` 包含项目介绍视频及字幕。
- `python tools/verify.py` 检查数据结构、文稿编号、分篇边界和手册引用关系。

勘误可提交 GitHub Issue，注明文稿标题、原文页码或段号、相关笔记段落及建议修改。
